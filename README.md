# base-dados-lgpd
# Análise de Dados sobre a LGPD

## Sobre o projeto

Este repositório reúne os arquivos e o código utilizados no desenvolvimento de uma pesquisa sobre a Lei Geral de Proteção de Dados Pessoais (LGPD).

O trabalho utiliza dados relacionados à aplicação da LGPD, incluindo informações da base APDados e registros complementares, para realizar o tratamento, a organização e a análise dos dados. As análises são desenvolvidas em Python, com geração de tabelas, gráficos e resultados que auxiliam na investigação do tema.

## Organização do repositório

O repositório está organizado da seguinte forma:

- **`dados/`**: contém os arquivos de dados em formato CSV utilizados na pesquisa.
- **`caderno/`**: contém o notebook Jupyter (`.ipynb`) com o código desenvolvido para o tratamento dos dados e a realização das análises.
- **`README.md`**: apresenta informações sobre o projeto e orientações para utilização dos arquivos.

## Como executar

O notebook pode ser executado pelo Google Colab ou em um ambiente Python com suporte a Jupyter Notebook.

Para executar pelo Google Colab:

1. Acesse o Google Colab.
2. Abra o arquivo `Analise_APDados_LGPD_Versao_Final.ipynb`, disponível na pasta `caderno/` deste repositório.
3. Disponibilize os arquivos CSV da pasta `dados/` no ambiente de execução.
4. Confira os caminhos dos arquivos utilizados no código.
5. Execute as células do notebook em ordem.

Durante a execução, o notebook realiza as etapas de preparação e análise dos dados, gerando as tabelas, os gráficos e os demais resultados utilizados na pesquisa.

## Tecnologias utilizadas

- Python
- Jupyter Notebook
- Google Colab
- Bibliotecas Python para manipulação, análise e visualização de dados.

## Observações

Os arquivos CSV disponibilizados neste repositório correspondem aos dados utilizados no desenvolvimento da pesquisa. As etapas de tratamento e análise estão documentadas no notebook.

Para reproduzir os resultados, é necessário utilizar os arquivos de dados correspondentes e executar as células do notebook na sequência apresentada.
